# Riset Strategi Trading

Tujuan:

- simpan hasil backtest eksplorasi
- cegah strategi mentah dianggap siap live

- `comparison.md` = definisi dan beda strategi
- `experiment-plan.md` = aturan uji coba
- `../../output/strategy_december_backtest.md` = hasil backtest dari Desember
